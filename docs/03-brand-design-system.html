Foundations

Typography

Plus Jakarta Sans is the single typeface across the product, in weights 300–800. One intentional cap keeps the UI from shouting: globally font-black maps to 700 and font-extrabold maps to 600 — headings stay confident, never heavy.

Components

UI system

The interface is built from shadcn/ui-style primitives on Radix + Tailwind, with a consistent 0.75rem corner radius. Loading uses skeletons, not spinners; sensitive values are masked by default.

Radius 0.75rem

One corner radius across cards, inputs, dialogs, and pills for a cohesive surface.

Skeletons over spinners

Lists and cards load with layout-shaped skeletons, so the page never jumps.

Masked sensitive data

SensitiveData hides balances and identifiers until intentionally revealed.

Voice & tone

FinFlo handles other people's money, so the voice is precise, confident, and trustworthy — never breezy, never alarming. Copy explains, states limits plainly, and earns trust through clarity.
